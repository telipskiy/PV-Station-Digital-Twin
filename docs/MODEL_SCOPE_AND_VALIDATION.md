# Межі застосовності та валідація моделі

## Призначення

Цифровий двійник призначено для порівняння структур електричної схеми СЕС у часовому квазіусталеному режимі. Змінними проєктування є кількість модулів у стрінгу, число стрінгів, тип топології (`string`, `multi-string`, `central`), кількість і номінал інверторів, а також довжини DC та AC кабелів.

Функція `create_topology_config` формує однозначне відображення «стрінг → інвертор». Функція `evaluate_pv_station` обчислює миттєві потоки потужності з енергетичним балансом. `run_simulation_suite` виконує відтворюваний параметричний експеримент та експортує таблицю результатів.

## Реалізовані залежності

- Миттєва потужність стрінгу визначається за MPP-параметрами модуля, опроміненістю та температурною поправкою.
- Втрати DC-збірника: `P_dc,loss = Σ I_string² R_dc,string`; опір кожного стрінгу залежить від його двобічної довжини.
- Інвертор обмежує активну потужність власним номіналом; надлишок реєструється як clipping.
- Втрати трансформатора: постійна складова втрат холостого ходу та квадратична складова навантажувальних втрат.
- Втрати AC-кабелю: `P_ac,loss = 3 I² R_ac(T)`, де `R_ac` прямо пропорційний довжині кабелю.
- Екран обмежень перевіряє діапазон DC-напруги, допустимий струм DC/AC кабелів та завантаження трансформатора. Допустимі струми задаються користувачем, оскільки залежать від способу прокладання, температури, групування та інших умов.

## Необхідна наукова обережність

Поточна модель не є моделлю комутаційних перехідних процесів. Її результати не можна використовувати як доказ значень THD, спектра гармонік, стійкості PLL, електромагнітних перехідних процесів, захисту або відповідності мережевому коду. Для цих задач потрібно окремо параметризувати й валідувати Simscape Electrical / Specialized Power Systems модель за паспортними даними обладнання та вимірюваннями.

Згенеровані профілі є синтетичними та детермінованими лише для регресійного тестування. Для дисертаційних висновків їх слід замінити виміряними або метеорологічними даними з зафіксованим джерелом, часовою роздільністю, контролем якості та періодом спостережень.

Економічні коефіцієнти в `init_pv_station_main.m` — сценарні припущення, а не ринкові котирування. Їх потрібно актуалізувати для кожного дослідження, зазначивши дату, валюту, географію та першоджерело.

## Мінімальна верифікація

```matlab
addpath(genpath(fullfile(pwd, 'scripts')));
test_topology_core();

results = run_simulation_suite( ...
    'ModulesPerString', [8 10 12], ...
    'NumberOfStrings', [2 5 10], ...
    'Topology', {'string','multi-string','central'});
```

Регресійний тест перевіряє, що стрінгова топологія призначає один інвертор на стрінг, а зміна довжин DC та AC кабелів змінює втрати. Перед серією експериментів слід додати перевірки параметрів модулів, перерізів кабелів, допустимих струмів, рівнів напруги та паспортних ККД.
